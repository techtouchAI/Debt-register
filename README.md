نظام متكامل وشامل لإدارة المكتب يعمل **بدون انترنت تماماً** - مصمم خصيصاً لإدارة المخزن والعملاء والفواتير والديون.

## ✨ المميزات الرئيسية

### 🏢 الإعدادات الأساسية
- **بيانات المكتب**: اسم المكتب، الهاتف، العنوان، الشعار (Logo) - تظهر تلقائياً في ترويسة كل فاتورة ووصل
- **الوضع الليلي/النهاري**: تبديل فوري مع حفظ التفضيل
- **إدارة المستخدمين (بدون انترنت)**: مدير (كل الصلاحيات) وموظف مبيعات (البيع والقبض وإضافة الزبائن فقط) - نظام محلي 100%
  - رمز الدخول (PIN) اختياري لكل مستخدم: يمكن تفعيله أو تغييره أو تعطيله، مع زر قفل لتبديل المستخدم وإيقاف مؤقت بعد 5 محاولات خاطئة
  - كل صفحة وزر محروس بصلاحية المستخدم، وسجل النشاطات يسجّل اسم من نفّذ العملية
  - رمز استرداد (12 رقماً) يعيد تعيين رمز المدير عند نسيانه
  - التثبيت الجديد يبدأ بمدير واحد بلا رمز معروف؛ يختار المدير لاحقاً إن كان يريد حماية الدخول برمز
- **العملة**: دينار عراقي، دولار، ريال، إلخ

### 📦 إدارة المخزن (قاعدة بيانات المواد)
- إضافة مواد بسرعة: الاسم والوحدة والكمية في نموذج واحد
- تفاصيل: اسم المادة، الكمية، سعر البيع، ومتوسط/آخر تكلفة محسوبان من حركات المخزون
- إدخال مخزون أو تسوية يدوية مؤرخة بتكلفة وحدة وملاحظة، مع تحديث ذري للكمية ومتوسط التكلفة
- **تنبيهات الجرد الذكية**: لون مميز وإشعار عند نفاد مادة
- فئات ووحدات متعددة (قطعة، كيس، لتر، كغم...)
- حساب قيمة المخزون والأرباح المحتملة

### 👥 إدارة العملاء (سجل الزبائن)
- بطاقة الزبون: الاسم الثلاثي/الرباعي، الهاتف، العنوان، ملاحظات
- **عرض إجمالي الديون بجانب كل زبون مباشرة**
- بحث ذكي بالاسم أو الهاتف أو العنوان
- كشف حساب تفصيلي لكل زبون

### 🧾 المبيعات والفواتير (قلب التطبيق)
- **إنشاء فاتورة جديدة**: نقدي أو آجل
- **تحديد الزبون**: من قاعدة العملاء أو زبون عابر للنقدي
- **الفاتورة الذكية**:
  - حقل بحث ذكي للمادة
  - السعر المفرد ينزل تلقائياً
  - إدخال الكمية → حساب تلقائي: الكمية × السعر = المجموع
  - حساب الإجمالي، الخصم، المتبقي
- **تاريخ دقيق**: يوم وشهر وساعة (مثلاً 22 أو 23 بالشهر)
- **الطباعة والتصدير**:
  - معاينة وحفظ وطباعة بمقاس A4 فقط
  - زر تصدير PDF لإرسال واتساب
- **تحديث المخزن التلقائي**: خصم الكميات فور الحفظ
- جميع الفواتير قابلة للتعديل والحذف مع إرجاع الكميات

### 💳 الديون والتسديدات (النظام الآجل)
- **كشف حساب زبون تفصيلي**: جدول زمني لكل مسحوباته، المواد، التواريخ
- **تراكم الديون تلقائياً**: جمع الفواتير الآجلة
- **نافذة القبض**:
  - إدخال المبلغ المسدد (مليون، مليونين...)
  - تاريخ التسديد
  - خصم فوري من إجمالي الدين وإظهار المتبقي
- **وصل قبض**: معاينة وطباعة A4 تثبت التسديد والرصيد المتبقي
- حماية: لا يمكن حذف زبون مدين

### 📊 التقارير والإحصائيات
- **حركة الصندوق (الكاش اليومي)**: إجمالي النقدية اليومية - الغلة اليومية
- **تقرير الديون الشامل**: جميع المدينين والمبالغ وإجمالي المطلوب في السوق
- **كشف حركة مادة**: متى بيعت، لمن، الكمية المتبقية، الأرباح
- **تقرير الأرباح**: مبيعات، تكلفة، صافي ربح، هامش
- **قيمة المخزون**: إجمالي قيمة المواد، منخفضة، نافدة
- تصدير التقارير JSON

### 🔔 نظام الإشعارات
- **داخل التطبيق**: جرس مع عداد غير مقروء
- **خارج التطبيق**:
  - **Android**: إشعارات منبثقة عبر Capacitor Local Notifications
  - **Windows 10/11**: إشعارات نظام عبر Electron Notification API + Web Notifications
- تنبيهات: نفاد مخزون، ديون كبيرة، نسخ احتياطي

### 💾 الصيانة وأمان البيانات (حرج جداً)
- **نظام النسخ الاحتياطي**:
  - زر تصدير يدوي
  - **حفظ في مجلد «إدارة المكتب» مع اسم المكتب والتاريخ**: `اسم_المكتب_نسخة_احتياطية_2026-01-15_14-30-00.json`
  - **النسخة كاملة**: بيانات المكتب والشعار والإعدادات، المستخدمون، المواد، الزبائن، الفواتير وبنودها، التسديدات، دفتر ذمم الزبائن، حركات المخزون، الإشعارات، سجل النشاطات، وعدّادات ترقيم المستندات — مع عدد سجلات كل جدول وبصمة سلامة (SHA-256)
  - **معاينة قبل الاستعادة**: اسم المكتب وتاريخ النسخة وعدد السجلات قبل تأكيد الاستبدال
  - **نسخ احتياطي تلقائي**: كل 30 دقيقة / ساعة / يوم حسب الإعداد
  - **عند الاستيراد**: فحص صارم للبنية والمراجع المالية والمخزنية قبل أي كتابة، ثم استعادة ذرية للبيانات السليمة
  - يعمل على فلاش ميموري أو تصدير ملف
  - يحمي حقوق المكتب في حال تعطل الحاسبة أو فيروس
- سجل النشاطات (Activity Log)
- حذف جميع البيانات مع تأكيد نصي

### 🎨 الواجهة الأمامية (UI/UX)
- **Dashboard بسيطة**: أزرار كبيرة وواضحة: [فاتورة بيع جديدة]، [تسديد دين]، [إضافة مادة]، [الزبائن والديون]
- تصميم احترافي: TailwindCSS، ألوان هادئة (أخضر)، RTL كامل
- متجاوب 100% - موبايل وتابلت وديسكتوب
- **واجهة عربية بالكامل**: لا كلمة إنجليزية في أي نص يظهر للمستخدم (الإشعارات، الأخطاء، أسماء الملفات، أرقام المستندات ف-/ق-/ش-) — يتحقق منه اختبار آلي
- **اسم المكتب في الرئيسية**: يظهر وحده بخط متوسط، ويتحرك تلقائياً إذا تجاوز المساحة المتاحة (ويتوقف عند مرور الفأرة)
- خط عربي مدمج داخل التطبيق: Cairo (يعمل دون إنترنت)
- PWA - يعمل كتطبيق أصلي

### 🤖 Android APK (بدون انترنت)
التطبيق مبني ليعمل كـ PWA داخل WebView مع إمكانية الوصول لنظام الملفات والإشعارات.

**المتطلبات**: Node.js + Android Studio + JDK 17

```bash
# 1. بناء الويب
npm run build

# 2. تثبيت Capacitor (مرة واحدة)
npm install @capacitor/core @capacitor/cli @capacitor/android @capacitor/app @capacitor/filesystem @capacitor/local-notifications @capacitor/share

# 3. إضافة منصة Android
npx cap add android

# 4. نسخ البناء ومزامنة
npx cap sync android

# 5. فتح في Android Studio وبناء APK
npx cap open android
# ثم في Android Studio: Build > Build APK
```

**مميزات Android**:
- حفظ النسخ والمستندات في `المستندات/إدارة المكتب/` مع التاريخ والاسم
- إشعارات منبثقة خارج التطبيق
- يعمل بدون انترنت تماماً
- أيقونة واسم عربي

### 🪟 Windows 10/11 (برنامج مخصص)
**المتطلبات**: Node.js + Electron + electron-builder

```bash
# 1. تثبيت Electron (مع تخطي التحميل إذا كان هناك مشكلة شبكة)
npm install electron electron-builder --save-dev

# 2. بناء الويب
npm run build

# 3. بناء مثبت Windows
npx electron-builder --win --x64
# أو
npm run electron:build

# الناتج في مجلد release/:
# - OfficeManager-Setup-1.0.0.exe (مثبت NSIS)
# - OfficeManager-Portable-1.0.0.exe (نسخة محمولة)
```

**مميزات Windows**:
- مثبت احترافي مع اختصار سطح المكتب وقائمة ابدأ
- حفظ النسخ والمستندات عبر حوار حفظ Windows (بتسميات عربية) في `Downloads/إدارة المكتب/`
- نفس صفحات وميزات نسخة أندرويد، مع تكييف سطح المكتب: قائمة سياق عربية، تكبير/تصغير بـ Ctrl+عجلة الفأرة يُحفظ، أشرطة تمرير أعرض للفأرة، استعادة موضع التمرير عند الرجوع، ومنع إفلات ملف من استبدال الواجهة
- الضغط على إشعار النظام يُظهر نافذة التطبيق
- إشعارات نظام Windows 10/11
- يعمل بدون انترنت، بيانات محلية في IndexedDB
- متوافق تماماً مع Windows 10 و 11 (x64)

**ملفات Electron موجودة**:
- `electron/main.cjs`: النافذة الرئيسية، حفظ النسخ، الإشعارات
- `electron/preload.cjs`: جسر آمن بين الويب والنظام

## 🔒 الأمان والعمل بدون انترنت

- **100% Offline**: لا يوجد أي طلب شبكة، لا API، لا Firebase، لا تحليلات
- **IndexedDB**: جميع البيانات محفوظة محلياً في المتصفح/التطبيق
- **معاملات ذرّية**: حفظ الفاتورة (بنود + مخزون + دفعة مقدمة) ينجح كلياً أو يفشل كلياً
- **رموز الدخول**: تُخزَّن كبصمة SHA-256 مع ملح، ولا تظهر في الواجهة أبداً، مع إيقاف مؤقت بعد محاولات خاطئة متتالية
- **نسخ احتياطية محقَّقة**: أي ملف مستورد يمر بفحص بنية وتطهير أنواع قبل الكتابة
- **طباعة آمنة**: كل النصوص المُدخلة تُهرَّب قبل إدراجها في صفحة الطباعة (منع XSS)
- **Electron**: عزل السياق + sandbox + منع تنقّل النافذة لمصادر خارجية + نسخة وحيدة
- **PWA**: يعمل حتى بدون انترنت بعد أول زيارة (Service Worker)
- **النسخ الاحتياطي**: ملف JSON للتصدير اليدوي + نسخ داخلية تلقائية داخل التطبيق

## 🖥️ غلاف Tauri المكتبي (اختياري)

`desktop/` يضم مشروع Tauri v2 يغلّف **تطبيق الويب المبني** (`dist/`) — النسخة الحقيقية الكاملة (فواتير، مخزن، ديون، قاعدة بيانات محلية) — وينتج مثبتات Windows (NSIS/MSI) وAPK أندرويد أصلية أخف من Electron.

يتطلب Rust وأدوات Tauri، وبعد تشغيل `npm install` في جذر المشروع:

```bash
cd desktop
npm ci
npm run dev                              # تطوير (يبني الويب وينسخه تلقائياً)
npm run build -- --bundles nsis,msi      # Windows
npm run android:init && npm run android:build   # Android
```

لا يحتاج نسخ ملفات يدوياً: `desktop/scripts/copy-assets.mjs` يبني الجذر ثم ينسخ `dist/` كاملاً إلى `desktop/src-tauri/dist/` قبل كل أمر.

| `OfficeManager-Android` | APK موقع بإصدار Release (Capacitor + Gradle) بتوقيع الإنتاج إن وُجدت الأسرار، أو مفتاح CI مؤقت للاختبار |
| `OfficeManager-Windows` | Portable EXE لإصدار Windows 10/11 (electron-builder) |

**النشر:** اعمل وسم `v*` (مثل `git tag v1.1.0 && git push origin v1.1.0`) فتُرفق القطع الثلاث تلقائياً في GitHub Release مع ملاحظات إصدار مولّدة.

### أسرار توقيع Android للإنتاج

بدون هذه الأسرار يظل الـ APK قابلاً للتثبيت لكنه بمفتاح CI مؤقت لا يصلح للتحديثات فوق نسخة سابقة.

| Secret | الوصف |
|---|---|
| `ANDROID_KEYSTORE_BASE64` | ملف keystore مشفر بـ Base64 كسطر واحد (`base64 -w 0 release.jks`) |
| `ANDROID_KEYSTORE_PASSWORD` | كلمة مرور keystore |
| `ANDROID_KEY_ALIAS` | اسم المفتاح |
| `ANDROID_KEY_PASSWORD` | كلمة مرور المفتاح (اختياري إن كانت نفسها) |

## 🛠 استكشاف الأعطال

- **ومضة ثم شاشة سوداء عند الفتح:** السبب التاريخي (مشغّل Electron بمسارات مطلقة + BrowserRouter تحت `file://`) أُصلح؛ إن ظهر عندك من نسخة قديمة: حدّث التطبيق ثم اضغط "مسح ذاكرة التخزين المؤقت وإعادة التحميل" من شاشة الخطأ، أو احذف بيانات نطاق التطبيق من المتصفح.
- **شاشة خطأ "حدث خطأ غير متوقع":** هي حاجز الأخطاء الجديد — تعيد المحاولة أو تحميل كامل بدل الشاشة الصامتة؛ بياناتك في IndexedDB محفوظة.
- التفصيل الكامل لأنماط البناء المحلية في [BUILD_GUIDE.md](BUILD_GUIDE.md).
